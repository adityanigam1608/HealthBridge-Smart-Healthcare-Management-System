# HealthBridge – Smart Healthcare Management System

## Overview
HealthBridge is a full-stack healthcare management system developed using Java and Maven. It enables patients and doctors to manage appointments through a secure, role-based web application.

## Features
- Patient Registration & Login
- Doctor Registration & Login
- Book Appointments
- View Appointment Status
- Doctor Dashboard
- Approve/Reject Appointments
- Session-Based Authentication
- MySQL Database Integration

## Tech Stack
